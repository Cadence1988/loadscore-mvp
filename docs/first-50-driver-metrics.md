# First 50 Driver Metrics Specification

All metrics begin at zero. Do not backfill developer testing as driver activity.

## Acquisition

Sessions, legitimate referral/landing source, extension opens.

## Activation

First load calculated, first profile saved, first comparison, first parser use.

## Engagement

Calculations per active installation, comparisons, minimum-rate/broker guidance, extension use, copied/shared results.

## Retention

Returning installation, repeat-day usage, and Day 7 only after enough elapsed time and consented central data exist.

## Product quality

Positive/negative recommendation feedback and structured reason/usefulness codes.

## Word of mouth

Result copies, native shares, later attributed referral visits and activations.

## Dashboard readiness

The provider dashboard should show event totals, unique anonymous installations, activation funnel, repeat-day cohort, feature adoption, feedback ratio, and copy/share events. Central dashboard is not operational until the founder selects/configures a provider and verifies consented events end to end.
