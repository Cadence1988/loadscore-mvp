# Operating Modes

Updated: 2026-08-12

LoadScore now provides three driver-controlled matching contexts while preserving the same underlying score:

- **Preferred:** the driver's existing Phase 10A thresholds migrate here and remain the default.
- **Flexible:** editable LoadScore starter defaults relax several requirements to keep moving.
- **Recovery:** editable lower thresholds can identify repositioning opportunities without hiding weak economics or promising future freight.

Only one mode is active. LoadScore never switches modes automatically. Cross-mode labels show whether a load fits Preferred, Flexible, or Recovery, while saved-load ranking remains score, estimated profit, then all-in RPM.

Preferred and avoided destination lists remain global so an avoided destination stays excluded unless the driver deliberately edits that list. All threshold settings and the active mode are stored locally. Flexible/Recovery defaults are product starting points, not industry standards or financial advice.
