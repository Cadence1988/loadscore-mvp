# First-Driver Beta Hardening

Updated: 2026-08-12

Unknown deadhead no longer receives an ordinary trusted evaluation. Web, extension, highlighted parsing, pasted text, and CSV distinguish missing deadhead from confirmed zero. A zero is accepted only when supplied or deliberately confirmed.

The calculator may display a clearly labeled provisional estimate to help correction, but it cannot mode-match, save to comparison, notify, or rank in Top 7 until deadhead is supplied. Bulk provisional rows appear in a separate unranked group. This prevents missing deadhead from winning through an optimistic zero-mile assumption.

The first-run guide explains truck inputs, targets, Operating Modes, and complete versus provisional results. A clearly synthetic example load is available. Operating Modes are described as driver-selected matching rules, not subscriptions, and Recovery never changes LoadScore.

Required for a complete evaluation: origin, destination, positive rate, positive loaded miles, and known deadhead (including explicitly confirmed zero). Timing, equipment, weight, stops, references, and expiration remain optional context. Reload estimates retain curated/manual/default provenance and are not live load-board data.
